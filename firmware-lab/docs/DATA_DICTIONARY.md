# Laboratory data dictionary

All CSV files are generated by `lab/native_experiments.cpp` calling original public APIs. Values are synthetic experiment results, not observed sensor measurements.

| File | Granularity | Main fields and units |
|---|---|---|
| `physio.csv` | 1,155 independent 10 s windows | completeness and valid_fraction 0–1; motion_mg input; quality 0–100 or 255 null; artifact_flags/channel_flags bitmasks; hr bpm×10 or 65535 null; spo2 %×10 or 65535 null; ppg_samples count; motion_rms mg |
| `physio_cases.csv` | Seven named cases | quality 255 null; artifacts/channels bitmasks; hr/spo2 wire sentinel rules above |
| `station_input.csv` | Downsampled 25 ms trace | time_s; accel_z_mg; angle_deg; pressure_pa; gas_mv; mic_raw ADC count; pir/sos boolean |
| `station.csv` | 260 nonoverlapping 1 s windows | time_s = window end; peak_cg deviation from 1g in centi-g; rms_mg; tilt_ddeg and tilt_delta_ddeg tenths of degree; pressure_delta_pa nonnegative recent maximum change; gas_mv and baseline_mv; sound_index peak-to-peak ADC; flags; quality; sensor_flags |
| `events.csv` | Each drained native event | time_s is native event timestamp; type/name; level 0 info,1 notice,2 warning,3 urgent; value_x1000 is event-specific |
| `button.csv` | 5 ms steps | time_ms; raw and active boolean; action 0 none,1 raised,2 reset; presses count |
| `link.csv` | 100 ms supervision steps | time_ms; states 0 unknown,1 up,2 lost; ages ms since last received frame |
| `buffer.csv` | Each scripted queue operation | occupancy/evicted/sent/acked counters; selected_seq −1 when no send |
| `buffer_edge.csv` | Four record identities | priority 0 telemetry or2 urgent; retained boolean |

## Event values

The generic field name `value_x1000` must be interpreted with the event type. Impact values are g×1000 (mg), tilt is degrees×1000, pressure is Pa×1000, loud sound is ADC peak-to-peak×1000, gas is volts×1000 (mV), and presence is 1000 or0. The scenario does not plot these heterogeneous quantities on a common magnitude axis. See the authoritative mapping in `firmware/lib/umsf_proto/src/umsf_proto.c`.

## Null handling

The native CSVs retain wire sentinels for auditability. Plotting converts specific sentinel fields to NaN. Unsigned16 null is65535; unsigned8 null is255; signed16 null is−32768. Never apply sentinel conversion to bitfields without considering their protocol semantics. `station.csv` baseline stays65535 before warmup; the in-memory plotting table converts it to missing values.

## Deterministic stimulus schedule

PIR high10–11 s; impact30.000–30.030 s; sound30.000–30.100 s; pressure step30.000–30.400 s; tilt12° during60–90 s; SOS state120–125 s; gas warmup180 s; gas voltage1500 mV at200–220 s,1200 mV at220–230 s, otherwise1000 mV. Intervals are left-inclusive and right-exclusive. Native acceleration/microphone tick is5 ms; pressure50 ms; gas100 ms. CSV input saving at25 ms is not the full-rate stimulus stream; the harness is its exact specification.
