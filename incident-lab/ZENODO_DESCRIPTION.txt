DESCRIPTION
UMSF Incident Lab is a self-contained English research notebook for reproducible analysis of multisensor monitoring and incident-support data. The notebook embeds the original Python analytical core, schemas, tests and example data in a SHA-256-verified payload. It runs without an external dataset download, a GitHub repository, API credentials or mounted Google Drive. Missing analysis dependencies are installed by the setup section. After the three setup cells, every analysis cell is self-sufficient: shared results are computed on first use and cached, so any cell can be run alone, in any order, or after a kernel restart.

The project includes 67 notebook cells, of which 34 are executable, and 30 figure sets exported in PNG and SVG. Analyses cover data provenance, missing channels, arrival delays, activity-conditioned synthetic baselines, detector confusion matrices, false-negative decomposition, threshold and seed sensitivity, roster-based monitoring coverage, deduplication, conflicting-identity quarantine, and arrival-cutoff-aware summaries. A browser-native offline explorer provides node, channel and reporting-time controls for the simulated incident scenario. Additional sections demonstrate bench-record interpretation, binary protocol decoding and fragmentation, host-side cryptographic checks, capacity-constrained service allocation and analytical storage sizing.

The supplied incident scenario comprises 2,024 physiological records, 7,660 stationary records and 30 events. Study A generates 40,320 synthetic feature records and evaluates 4,800 zone-minutes. Study B processes 2,173 input lines and exports 2,159 nonconflicting records. Local execution verified all 34 executable cells in one sequential run and each of the 31 analysis cells alone in a fresh kernel, all 58 original tests and all 25 reference-comparison rows. Execution evidence, environment versions and checksums are included. Hosted Google Colab frontend execution has not been independently tested.

Study A and Study B are synthetic re-implementations constructed to reproduce supplied manuscript aggregates; matching these values is not independent empirical validation. Stage 1 is a supplied bench transcription with a synthetic HR test field, and Stage 2 is a synthetic re-enactment. No human-subject data are included. Missing observations remain missing; uncalibrated gas voltage is not interpreted as gas concentration, and communication loss is not treated as evidence of injury or collapse. The software makes no clinical, structural or certified safety claims and performs no actuation or responder dispatch. Notebook release 1.2.0 preserves analytical core version 1.0.0.
