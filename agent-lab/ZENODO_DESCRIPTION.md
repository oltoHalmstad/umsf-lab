## Description

This English computational laboratory converts umsf-incident-ai-agent 1.0.0 into a self-contained Google Colab-compatible notebook. It embeds the original source, two synthetic incident scenarios and the companion P1 incident fixture. The notebook runs 116 original tests without skips and 44 supplied analytical checks, then produces 30 explanatory figures, an offline interactive replay explorer, CSV/JSON outputs, audit evidence and a rendered HTML report. Experiments cover robust personal references, missing channels, persistent flags, coverage-aware group decisions, source-qualified incident state, exact lexicographic rescue assignment, exact multi-resource service-continuity allocation, heuristic recovery scheduling, proposal authority and hash-chain audit integrity. Both scenarios are replayed at 41 chronological cutoffs. Deterministic algorithms compute all decisions; no external language-model API or credentials are required. Every plan remains a proposal. All records are synthetic and the project has not been validated against real rescue operations. The original source and localized examples are retained verbatim for provenance; the new notebook, figures, explorer and documentation are English. After a three-cell setup, every analysis cell is self-sufficient and can run alone, in any order or after a kernel restart. All code cells were executed in a fresh local Jupyter kernel with only the notebook supplied, and each analysis cell was additionally executed alone in its own fresh kernel. Hosted Google Colab frontend execution and live LLM API compatibility were not directly tested.
